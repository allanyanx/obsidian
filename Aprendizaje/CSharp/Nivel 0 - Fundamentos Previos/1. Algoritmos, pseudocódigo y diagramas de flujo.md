#### 0.1. ¿Qué es programar?

Programar es darle a la computadores ordenes precisas y en orden sin ambigüedades.
#### 1. Algoritmos

Un **algoritmo** es una secuencia finita de pasos que resuelve un problema. Una receta de cocina es un algoritmo. Para ser bueno debe ser:

- **Preciso:** cada paso tiene un solo significado.
- **Finito:** termina en algún momento.
- **Ordenado:** el orden de los pasos importa.
- **Con entrada y salida:** recibe datos y produce un resultado.

**Ejemplo:** decidir si una persona puede entrar a un cine para mayores de 18.
1. Pedir la edad.
2. Si la edad es 18 o más, permitir la entrada.
3. Si no, negar la entrada.
#### 2. Pseudocódigo

Es un algoritmo escrito en lenguaje casi humano, con estructura de código pero sin la sintaxis de un lenguaje real. Sirve para pensar la lógica antes de preocuparte por la sintaxis.

```
INICIO
  LEER edad
  SI edad >= 18 ENTONCES
    MOSTRAR "Puede entrar"
  SINO
    MOSTRAR "No puede entrar"
  FIN SI
FIN
```

Ese mismo algoritmo en C# se vería de la siguiente manera:
```C#
Console.Write("Edad: ");
int edad = int.Parse(Console.ReadLine());

if (edad >= 18)
    Console.WriteLine("Puede entrar");
else
    Console.WriteLine("No puede entrar");
```

#### 3. Diagramas de flujo

Son la versión **visual** del algoritmo. Cada forma tiene un significado:

| Forma         | Significado               |
| ------------- | ------------------------- |
| Óvalo         | Inicio / Fin              |
| Rectángulo    | Proceso (una operación)   |
| Paralelogramo | Entrada / Salida de datos |
| Rombo         | Decisión (sí/no)          |
| Flechas       | Dirección del flujo       |
|               |                           |
El ejemplo del cine queda así:

``` 
   (Inicio)
      │
 /Leer edad/
      │
   <edad >= 18?>──No──► /"No puede entrar"/──┐
      │Sí                                    │
 /"Puede entrar"/                            │
      │                                      │
      └──────────────► (Fin) ◄───────────────┘
```
