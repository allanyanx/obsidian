#### Tipado estático
Los tipos, como variables fijas se declaran, y se verifican en tiempo de compilación.

``` C#
int edad = 25;
edad = "hola";   // Error al compilar
```

#### Tipado dinámico
Los tipos se verifican e infieren en tiempo de ejecución y por lo general al definir una variable no se declara su tipo, el propio interprete lo sabe al leer el valor en si.

``` Javascript
edad = 25
edad = "hola"    # Válido
edad + 1         # Error solo al ejecutar esta línea
```
