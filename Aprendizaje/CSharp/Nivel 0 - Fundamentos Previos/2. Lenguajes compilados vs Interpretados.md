### Lenguajes compilados
Todo el código se traduce a un formato intermedio o lenguaje máquina antes de ser ejecutado mediante un compilador. 

**Ventajas**
* Velocidad de ejecución.
* Detecta errores antes de siquiera correr el programa.
* No necesitas el código fuente ni el compilador para ejecutarlo.
**Desventajas**
* Siempre requiere recompilar todo para ser ejecutado.
* El ejecutable solo es compatible para la plataforma para la que se compilo.

### Lenguajes Interpretados 
El código se lee línea a línea por un interprete en tiempo de ejecución, sin generar un ejecutable previamente.

Ventajas
* Se prueba rápido al no depender de un compilador.
* Cualquier sistema que tenga el interprete puede ejecutar el código.
Desventajas
* No marca los errores hasta que ejecutas esa parte en particular.
* Necesita el interprete en el entorno para ejecutar el código.

#### Código JIT (Just In Time )
Se utiliza un interprete para ejecutar el código línea por línea, sin embargo, el motor analiza que partes del código se están utilizando con más frecuencia, entonces procede a compilar esos bloques y traducirlos a código máquina, así la siguiente vez que se ejecute ese programa toma ese código nativo y no lo vuelve a interpretar.
