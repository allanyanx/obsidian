En ReactJS todo se renderiza a través de una etiqueta ```<div></div>``` en el fondo todo se compilar a código Javascript, por ello se pueden dividir en componentes que retornan código HTML

``` jsx
import Footer from "./components/Footer";
import Header from "./components/Header";
import MainContent from "./components/MainContent";

const App = () => {

  return (
    <div>

      <Header />
      <MainContent />
      <Footer />

    </div>
  );
};

export default App;
```
