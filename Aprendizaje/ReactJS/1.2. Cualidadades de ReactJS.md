### 1.2.1. Comportamiento de React con códido HTML
* Cuando se retorna un componente en react, este componente solo puede retornar una única etiqueta html que es declarada como un padre, es decir no se puede retornar varias etiquetas padre a la vez a menos que todos tengan el mismo padre en común.

``` JSX
const App = () => {

  return (
    <div>
      <WelcomeMessage />
    </div>
    <p></p> // ERROR
  );
};
```

* Por defecto no se pueden utilizar varios atributos con sus nombres nativos en react, porque varios de ellos corresponden a nombres de palabras reservadas en javascript como for, en su lugar se usan palabras como className o htmlFor en lugar de los atributos tradicionales para evitar errores de compilación.

``` JSX
const WelcomeMessage = () => {

  return (
    <div class= ""> // Se debe usar className
        <h1>Hello, World!</h1>
        <p>Welcome to learn JSX!</p>
    </div>
  );
};
```

* Las etiquetas html deben estar correctamente cerradas.

### 1.2.4. PROPS

Son argumentos que se pasan a los componentes de React, nos permiten pasar argumentos desde un componente padre a un componente hijo, y estos se pasan a través de atributos HTML.
![[Pasted image 20261106103533.png]]

* Paso de props de un padre a un hijo
``` JSX
const PropsExample = () => {
  return (
    //Pasa props al hijo
    < User nombre="allan" gay= "harold"/>
  )
}

//Espera props del padre
const User = (props) => {
    console.log(props);
    return <section></section>;
}

export default PropsExample;
```
