#### React: funcionamiento
Cuando se utiliza HTML, CSS y JS por lo general escupimos bullshit en cada uno de los archivos con la finalidad de crear una interfaz y darle funcionalidad, sin embargo en REACT todo se maneja con componentes en los archivos .jsx, estos componentes pueden ser pequeños como un boton o grandes como una dahsboard.

Dichos componentes siempre se retornan con la notación de función o arrow function, como sea más conveniente (pero siempre deben retornar código HTML):

``` jsx
//Notación de función
function App () {
  return <section>hello</section>;
}

//Arrow function
const App = () => {
  return <section>hello</section>;
}
```
